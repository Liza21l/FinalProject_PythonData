# Fullstack Data-Driven Banking Platform

## Опис проєкту

**Fullstack Data-Driven Banking Platform** — це вебзастосунок на Python, який поєднує обробку великих наборів даних, машинне навчання, алгоритми та структури даних, а також Flask backend із вебінтерфейсом.

Проєкт використовує дані про поведінку користувачів в інтернет-магазині, щоб аналізувати їхню активність, групувати користувачів і формувати рекомендації товарів.

## Основні можливості

### 1. Data Science та Machine Learning

- Очищення й підготовка даних.
- Формування ознак користувачів: перегляди, додавання до кошика, покупки та статистика сесій.
- Кластеризація користувачів за допомогою KMeans.
- Масштабування ознак через StandardScaler.
- Вибір кількості кластерів за допомогою методу Elbow.
- Класифікація активності користувачів за допомогою Random Forest.
- Оцінювання моделі за Accuracy, Precision, Recall та F1-score.
- Візуалізація кластерів користувачів за допомогою PCA.

### 2. Рекомендаційна система

Система аналізує поведінку користувачів і формує рекомендації товарів. Для оцінювання товарів використовується співвідношення покупок до переглядів. Рекомендації можуть формуватися окремо для кожного кластера користувачів.

### 3. Алгоритми та структури даних

У проєкті реалізовано:

- **Queue** — черга за принципом FIFO.
- **Stack** — стек за принципом LIFO.
- **Bubble Sort** — сортування бульбашкою.
- **Quick Sort** — швидке сортування.
- **Linear Search** — лінійний пошук.
- **Binary Search** — бінарний пошук у відсортованому списку.

### 4. Flask Backend

Backend забезпечує роботу вебзастосунку та API для:

- сортування й пошуку;
- роботи з чергою та стеком;
- отримання рекомендацій;
- перегляду журналу операцій;
- отримання статистики dashboard;
- отримання PCA-візуалізації.

Операції зберігаються в базі даних SQLite за допомогою Flask-SQLAlchemy.

## Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone <URL_ТВОГО_GITHUB_РЕПОЗИТОРІЮ>
cd FinalProject_PythonData
```

### 2. Створення віртуального середовища

```bash
python -m venv .venv
```

Активація у Windows:

```bash
.venv\Scripts\activate
```

### 3. Встановлення залежностей

```bash
python -m pip install -r requirements.txt
```

### 4. Запуск вебзастосунку

З кореневої папки проєкту виконай:

```bash
python -m web_app.app
```

Після запуску відкрий адресу, яку Flask виведе в терміналі, зазвичай `http://127.0.0.1:5000/`.

Для роботи з аналітичною частиною потрібні відповідні файли даних. Великі CSV-файли не обов'язково зберігаються в GitHub, тому їх може знадобитися отримати окремо.

## 🌟 Мої авторські доопрацювання (Custom Features)

### PCA-візуалізація кластерів користувачів

Реалізовано окрему візуалізацію результатів кластеризації. Метод PCA зменшує кількість вимірів ознак до двох, що дає змогу відобразити користувачів на двовимірному графіку та візуально досліджувати сформовані кластери.

### Рекомендації товарів за кластерами

Реалізовано окреме формування рейтингу товарів для кожного кластера користувачів на основі співвідношення покупок до переглядів. Це дає змогу враховувати відмінності між групами користувачів.
