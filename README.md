# Fullstack Data-Driven Banking Platform

## Опис проєкту

**Fullstack Data-Driven Banking Platform** — це навчальний вебзастосунок на Python, який поєднує Data Science, Machine Learning, алгоритми, структури даних, базу даних і веброзробку на Flask.

Проєкт використовує дані про поведінку користувачів інтернет-магазину для аналізу активності, сегментації користувачів і формування рекомендацій товарів. Вебінтерфейс також демонструє роботу алгоритмів сортування та пошуку, черги й стека.

## Основні можливості

### 1. Data Science та Machine Learning

- Очищення та підготовка великого набору даних.
- Обробка даних частинами (chunks) для зменшення використання оперативної пам'яті.
- Перевірка дублікатів у даних.
- Формування ознак користувачів: перегляди, додавання до кошика, покупки, видалення з кошика та статистика сесій.
- Масштабування числових ознак за допомогою `StandardScaler`.
- Кластеризація користувачів за допомогою `KMeans`.
- Вибір кількості кластерів за допомогою методу Elbow.
- Зменшення розмірності ознак за допомогою PCA.
- Класифікація активності користувачів за допомогою `RandomForestClassifier`.
- Підбір гіперпараметрів через `GridSearchCV`.
- Оцінювання моделі за метриками Accuracy, Precision, Recall і F1-score.
- Порівняння Random Forest із базовою моделлю `DummyClassifier`.

### 2. Рекомендаційна система

Рекомендаційна система формує рейтинги товарів окремо для кластерів користувачів.

Для оцінювання товарів використовується співвідношення кількості покупок до кількості переглядів. Також враховується мінімальна кількість переглядів товару, щоб уникати рекомендацій на основі надто малої кількості спостережень.

У вебінтерфейсі можна переглядати рекомендації та фільтрувати їх за кластером користувачів.

### 3. Алгоритми та структури даних

У проєкті реалізовано:

- **Queue** — черга за принципом FIFO (First In, First Out).
- **Stack** — стек за принципом LIFO (Last In, First Out).
- **Bubble Sort** — сортування бульбашкою.
- **Quick Sort** — швидке сортування.
- **Linear Search** — лінійний пошук.
- **Binary Search** — бінарний пошук у відсортованому списку.

Алгоритми сортування та пошуку можна перевіряти через вебінтерфейс. Черга обробляє елементи в порядку додавання, а стек дозволяє працювати з останньою доданою операцією.

### 4. Flask Backend та база даних

Backend побудований на Flask і забезпечує роботу вебзастосунку та API для:

- отримання статистики dashboard;
- роботи з чергою та стеком;
- перегляду журналу операцій;
- сортування та пошуку;
- отримання рекомендацій товарів;
- відображення інтерактивної PCA-візуалізації.

Для збереження операцій використовується SQLite, а взаємодія з базою даних реалізована через Flask-SQLAlchemy.

### 5. Вебінтерфейс

Вебпанель об'єднує функції аналітики, машинного навчання, алгоритмів і структур даних.

Інтерфейс використовує HTML, CSS та JavaScript для взаємодії з Flask API. Інтерактивний графік PCA відображається у вебпанелі за допомогою Plotly.

## Авторські доопрацювання (Custom Features)

### 1. Інтерактивна PCA-візуалізація кластерів користувачів

Реалізовано інтерактивну двовимірну візуалізацію результатів кластеризації `KMeans` за допомогою PCA та Plotly.

Візуалізація відображає користувачів у просторі двох головних компонентів, а колір точок відповідає кластеру. Під час взаємодії з графіком можна досліджувати розподіл користувачів і переглядати інформацію про окремі точки.

Графік інтегрований у вебпанель та генерується скриптом `ml_pipeline/pca_visualization.py`.

### 2. Порівняння Random Forest із Baseline

Реалізовано скрипт `ml_pipeline/compare_baseline.py` для порівняння Random Forest із базовою моделлю `DummyClassifier`.

Для оцінювання моделей використовуються Accuracy, Precision, Recall і F1-score.

Отримані результати:

| Метрика | Baseline | Random Forest |
|---|---:|---:|
| Accuracy | 0,5028 | 0,9208 |
| Precision | 0,0000 | 0,9103 |
| Recall | 0,0000 | 0,9326 |
| F1-score | 0,0000 | 0,9213 |

Random Forest показав кращі результати за всіма наведеними метриками на використаному тестовому розбитті.

### 3. Рекомендації товарів за кластерами

Реалізовано формування рейтингу товарів для кожного кластера користувачів на основі співвідношення покупок до переглядів.

Результати розраховуються окремим скриптом і використовуються вебзастосунком для показу рекомендацій. Користувач може вибрати кластер і переглянути відповідні товари.

### 1. Клонування репозиторію

Заміни `<https://github.com/Liza21l/FinalProject_PythonData>` на адресу свого репозиторію:

```bash

cd FinalProject_PythonData
```

### 2. Створення віртуального середовища

```bash
python -m venv .venv
```

Активація у Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 3. Встановлення залежностей

```bash
python -m pip install -r requirements.txt
```

### 4. Підготовка даних

Для повноцінної роботи аналітичної частини потрібні вхідні дані та згенеровані файли, які використовує застосунок.

Великі CSV-файли та збережені ML-моделі можуть не входити до Git-репозиторію. Якщо їх виключено через `.gitignore`, потрібно підготувати відповідні файли перед запуском функцій, які від них залежать.

Вихідні дані та моделі створюються скриптами з каталогу `ml_pipeline` у межах відповідних етапів обробки даних і навчання.
